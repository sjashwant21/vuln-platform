# Deployment Guide

This guide explains how to deploy the VulnAssess Platform to a single Linux VPS (e.g., DigitalOcean Droplet, AWS EC2, or Linode) using Docker Compose.

## Prerequisites

1. A Linux server (Ubuntu 22.04 LTS recommended) with at least 2GB RAM.
2. A domain name pointed to your server's public IP address (e.g., `vulnassess.example.com`).
3. SSH access to your server.

## Step 1: Initial Server Setup

SSH into your server and install Docker and Git:

```bash
# Update packages
sudo apt update && sudo apt upgrade -y

# Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Install Git
sudo apt install git -y
```

## Step 2: Clone the Repository

```bash
git clone https://github.com/sjashwant21/vuln-platform.git
cd vuln-platform
```

## Step 3: Configure Environment Variables

Copy the example environment file and generate your secure production secrets:

```bash
cp .env.example .env
make gen-secrets
```

Open `.env` using a text editor (like `nano .env`) and update the following values:

1. Replace the generated `POSTGRES_PASSWORD`, `REDIS_PASSWORD`, `SECRET_KEY`, and `JWT_SECRET_KEY` with the ones generated by `make gen-secrets`.
2. Add your **Groq API Key** (`GROQ_API_KEY`) and **NVD API Key** (`NVD_API_KEY`).
3. (Optional) Set `APP_ENV=production`.

## Step 4: Configure SSL / HTTPS (Certbot)

For production, you need valid SSL certificates. We'll use Let's Encrypt (Certbot).

First, install Certbot:
```bash
sudo apt install certbot -y
```

Generate a certificate for your domain:
```bash
# Replace YOUR_DOMAIN and YOUR_EMAIL
sudo certbot certonly --standalone -d YOUR_DOMAIN -m YOUR_EMAIL --agree-tos
```

Copy the generated certificates to the Nginx SSL directory:
```bash
mkdir -p nginx/ssl
sudo cp /etc/letsencrypt/live/YOUR_DOMAIN/fullchain.pem nginx/ssl/cert.pem
sudo cp /etc/letsencrypt/live/YOUR_DOMAIN/privkey.pem nginx/ssl/key.pem
sudo chown -R $USER:$USER nginx/ssl
```

*(Note: In a fully automated production environment, you would use a tool like Caddy or Traefik, or map the Let's Encrypt renewal directory directly to the Nginx container).*

## Step 5: Start the Platform

Build the production containers and start the stack in detached mode:

```bash
docker compose up -d --build
```

Wait a few seconds for the database to initialize, then run the database migrations:

```bash
docker compose run --rm migrate
```

## Step 6: Verify Deployment

Your platform is now live! 
- Access the frontend at: `https://YOUR_DOMAIN`
- Access the API Docs at: `https://YOUR_DOMAIN/docs`

## Updating the Platform

When you push new code to GitHub, you can update your deployment by running:

```bash
cd vuln-platform
git pull origin main
docker compose up -d --build
docker compose run --rm migrate
```

## Troubleshooting

Check the logs for all services:
```bash
docker compose logs -f
```

Check the logs for a specific service (e.g., the API or background worker):
```bash
docker compose logs -f api
docker compose logs -f worker
```
